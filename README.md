# UNiNUS Water Control

Home Assistant 補水監看與受保護手動控制，採「原生設備設定＋卡片快捷參數」的 C 方案。區域與水桶可依現場配置增減，每桶個別指定液位感測器，補水與告警開關各自選配。

## HA Marketplace 安裝

[在 Home Assistant Marketplace 開啟 UNiNUS Water Control](https://my.home-assistant.io/redirect/marketplace_repository/?owner=ivanlee1007&repository=uninus-water-control&category=integration)

也可到 Home Assistant **設定 → Marketplace → 從連結新增**，貼上本 GitHub 儲存庫網址，類別選 **整合（Integration）**，再安裝 UNiNUS Water Control。安裝後，到 **設定 → 裝置與服務 → 新增整合**，搜尋 UNiNUS Water Control。儀表板模組隨整合提供，依[儀表板使用說明](docs/NATIVE-DASHBOARD.md)加入，不必另裝卡片套件。

這是自訂儲存庫安裝方式，並非 Marketplace 預設目錄上架。

**從舊版更新前**，先建立並驗證一份更新前的完整 Home Assistant 設定備份，否則不能依程序回復 v1。請先閱讀[區域與水箱移轉、備份與復原](docs/TOPOLOGY-MIGRATION-ZH-HANT.md)。更新不會重新建立區桶 ID，也不會自動啟用設備。新版可保留舊式清單明確換綁後的參數；舊程式不理解其來源證明，因此未完成參數重新保存核對前不要直接降版，詳見[參數相容性](docs/CARD-SETTINGS-WIRE.md)。

## 設定與操作：C 方案

| 入口 | 負責項目 | 保存語義 |
| --- | --- | --- |
| 日常卡片的每桶快捷參數 | 補水上下限、低液位告警門檻與延遲、液位圖量程；可選沿用共用設定 | 管理員明確儲存後更新該桶共用後端設定，影響所有顯示此桶的卡片；取消不寫入 |
| Lovelace 卡片編輯器 | 此卡顯示的區桶、詳細狀態等顯示選項 | 由 HA 外層儲存／取消，只影響此卡，不修改設備及運轉參數 |
| 整合的原生設定（Options） | 增減區桶、正式名稱、來源及輸出綁定、安全啟用、最大運轉時間、移轉／復原，以及共用與單桶參數 | 使用整合唯一的設定與驗證邊界；不是第二份資料 |

快捷參數不提供設備換綁、安全啟用或最大運轉時間的捷徑。變更參數不會直接啟動輸出；保存後須讀回確認，遇到別處修改或來源變動須重新核對，不能自動重送。

保留液位圖、自適應排版與狀態摘要；通用設定、實體選擇、授權及 More info 沿用 HA。每桶亦提供可獨立放在原生 Tile 的液位實體。架構優先序與驗收見 [C 方案契約](docs/C-ARCHITECTURE.md)。

## 已有功能與使用限制

已有可增減的區域與水桶、原生液位實體、自適應總覽、選配的單桶手動補水與告警控制，以及不操作設備的門檻與延遲告警預覽。**目前門檻仍只影響唯讀預覽；自動補水、正式告警通知及實體設備驗收未完成。** 請先在測試 HA 使用模擬感測器和輸出。

- 區桶清單可多筆，但本階段只允許一桶啟用受保護手動控制；不宣稱完整多桶並行控制。
- 告警輸出歷史只提供有連續性證據的有限開／關變化，不代表完整操作人、命令原因與故障履歷。
- 啟用手動控制須有獨立裝置關斷保護。HA 服務成功或狀態回報不等於實際出水／停止；停止尚未確認時不可顯示已停止。
- 開發與隔離測試不修改 Jingan 的設定或設備，亦不以顯示配置直接控制原始實體。軟體驗證不等於現場驗收。

完整產品待辦及交付邊界見[開發路線圖](docs/ROADMAP.md)。
