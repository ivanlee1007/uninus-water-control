# C 方案：原生設備設定與卡片快捷參數

本文件是本輪修正的現行契約，取代 ROADMAP、P2/P4 階段文件及舊卡片設定說明中與此不一致的入口描述；歷史階段的執行證據不改寫。使用者已明確核准 C 方案。這不是自動補水或現場切換授權。

## 三層責任

1. **Lovelace 卡片編輯器只處理本卡顯示設定。** 支援選擇顯示區／桶（空白代表既有全部可讀清單，以保留舊設定）、詳細狀態顯示開關。以 config-changed 交給 HA 外層儲存／取消；不得讀寫私有設定、呼叫設備服務或發出 config_save/topology_save。
2. **日常卡片提供每桶「快捷參數」視窗。** 僅管理員在正常操作模式、連線有效及唯一 entry/穩定 zone/tank 身分可確認時可開啟。以既有 config_get/config_save 管道編輯該桶補水上下限、低液位告警門檻與延遲、液位圖量程。明確保留「沿用共用設定／此桶個別設定」語義，不在快捷視窗修改共用預設。取消／Escape／切換權限不寫入；僅顯式「儲存此桶參數」寫入，提示影響所有顯示此桶的卡片。
3. **原生整合 Options 為設備與安全設定入口。** 初次設定及 owned/legacy 清單都支援增減區桶、正式名稱、來源與輸出綁定、安全啟用、最大運轉時間、移轉／復原。已啟用控制的換綁／移除須走原生安全流程，輸出未 settled 時不保存。並提供原生參數設定表單，讀寫與快捷視窗完全相同的 Settings，涵蓋共用預設與每桶設定，非第二份持久化。

## 相容與安全

- 不重建 stable IDs，不清除既有值、不自動重新綁定，不變更獨立 cutoff 要求；任意區桶、重名及離線項目保留。
- 保留液位圖、自適應排版與受保護按鈕；以現有 HA 原生元件完成實體選擇與原生表單，不將所有外觀改成另一套新設計。
- 快捷讀取後凍結 revision/source_snapshot；數值成對驗證，一次保存；新來源／其他編輯衝突要明示重新讀取，不自動 rebasing 或重送。
- 快捷保存只有一個未結束 mutation owner；斷線／身份切換／關閉使舊回應失效，但不能當成已取消後端寫入。保存成功須新 config_get 獨立讀回吻合；不確定則顯示未確認，避免自動重送。
- 初次打開、取消、僅編輯卡片以及保存參數皆不得呼叫 switch/button/notify。目前門檻只影響唯讀預覽；不可暗示已啟用自動補水。現場驗收、自動補水、正式通知與完整操作履歷仍保留待辦。
- 後端 Registry 身分／綁定衝突／生命週期／授權一致；保存失敗或拒絕不得污染已生效設定。

## 驗收

- 修復 7 項審查缺陷：setup 失敗殘留 owner、OFF 卡死、native/card 驗證不一致、passive alias replacement、單位相容、隱藏資料清理、原生名稱同步。
- 原生 Options 真 Core Manager/HTTP：新增／改名／移除區桶、來源衝突拒絕、參數儲存後重開、取消零寫入、權限變更／卸載拒絕；owned/legacy 都覆蓋。
- Shipped card 真 Chromium：一般模式快捷開啟、數值輸入連續保焦、取消與儲存、新讀回、另一 client 修改衝突、斷線／同 ID 降權／刪桶與延遲回應、隱藏頁清理；手機／桌面幾何與鍵盤可用。
- 原生 Lovelace 外層編輯／取消／保存只修改卡片 config，config-changed 選擇能重開；舊 backend editor 的測試依入口遷移，保留所有 CAS/權限/耐久性斷言，不以刪除安全斷言換綠燈。
- 既有完整 pytest + tools/verify_native_dashboard.py 在整合後一次完整跑；先 focused RED→GREEN，SPEC 再品質／安全獨立審查，最多兩輪明確 blocker 修復。無部署、無 tag/release、無 merge；若發布採單一完整修正 PR。
